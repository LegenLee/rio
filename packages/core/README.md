# @rio-m3e/core

Framework-agnostic logic for [Rio](https://github.com/LegenLee/rio), a Material 3 Expressive implementation: component prop types, defaults, state, and accessibility attributes, plus the DOM behaviors components share (ripple, shape morph, springs, and drag).

Framework adapters such as [`@rio-m3e/vue`](https://www.npmjs.com/package/@rio-m3e/vue) are built on it, and install it for you. Install it directly only to build components of your own.
