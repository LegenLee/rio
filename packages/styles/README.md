# @rio-m3e/styles

Plain CSS for the components of [Rio](https://github.com/LegenLee/rio), a Material 3 Expressive implementation. It reads the `--rio-*` CSS variables that [`@rio-m3e/tokens`](https://www.npmjs.com/package/@rio-m3e/tokens) sets.

Framework adapters such as [`@rio-m3e/vue`](https://www.npmjs.com/package/@rio-m3e/vue) import these files for you. To use them directly, import them one by one:

```ts
import '@rio-m3e/styles/button.css';
import '@rio-m3e/styles/base/ripple.css';
```
